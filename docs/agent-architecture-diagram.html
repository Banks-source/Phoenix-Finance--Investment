Phoenix Finance — Subscription-Native LLM Access

Custom connectors in your existing Claude and ChatGPT plans — no API keys, no per-token billing

This is subscription, not API

  • • Custom connectors work on Claude Free, Pro, Max, Team and Enterprise — across claude.ai, Cowork, Desktop and mobile
  • • ChatGPT needs Plus or Pro for developer mode; free accounts can't add custom connectors
  • • Add it once under Settings → Connectors → Add custom connector, then it's available in normal chat
  • • Zero LLM API charges. Your only cost is hosting Phoenix, which Vercel's hobby tier likely covers

The catch worth knowing

  • • Claude connects to remote MCP servers from Anthropic's cloud, not from your device — even in Desktop and Cowork
  • • So a remote connector must be reachable on the public internet. localhost will not work for the web, mobile or Cowork clients
  • • Claude Desktop is the exception: it can also run a local stdio server directly, no public exposure
  • • If you skip ChatGPT and mobile, you can stay entirely local and never expose an endpoint at all

Suggested path

  • • Start with the local stdio server — Claude Desktop plus a local model, nothing public, fastest to working
  • • Add the remote connector only when you actually want Phoenix on your phone or in ChatGPT
  • • Keep the tier split either way: aggregates remote, raw detail local
  • • Read-only throughout, every call logged, no trade execution — ever
