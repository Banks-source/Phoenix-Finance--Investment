# Phoenix Finance

Personal finance app (budget + investment tracking + tax organisation) for Lloyd and Milani. Not a market product — household use only. This repo is the source of truth for product decisions and code.

- [`PRD.md`](./PRD.md) — what we're building and why, phased scope, locked category taxonomy.
- [`SOLUTION_DESIGN.md`](./SOLUTION_DESIGN.md) — architecture for v1, including the household data partition design.

## Status

v1 (Budget) in progress. See PRD §8 for the full phase plan (v2 Tax pack, v3 Kubera/investment thesis engine, v4 spending optimisation).

## Stack

Next.js 14 + TypeScript + Tailwind + shadcn/ui + Supabase + Recharts + Claude API + Vercel. PWA, web-first.
